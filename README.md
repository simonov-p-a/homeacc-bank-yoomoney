# HomeAcc: правила привязки — ЮMoney

Индивидуальные правила привязки банка **ЮMoney** для программы HomeAcc.

Файл `bank.json` описывает форму привязки: шаги инструкции, поля формы и
кнопки действий, а также эндпоинты OAuth. Программа HomeAcc рисует форму
по этим правилам и обновляет их автоматически из фида.

Входит в фид `simonov-p-a/homeacc-banks` (управляющий индекс банков).
